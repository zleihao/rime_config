# 描述



## Windows

下载路径：[RIME | 中州韻輸入法引擎](https://rime.im/)

用 windows 文件夹下的 **data** 文件夹下的內容替换本地 **C:\Program Files\Rime\weasel-0.17.4\data** 文件夹下的內容。



## IOS

下载：打开 **App Store** 搜索 **仓输入法**



建议采用 Wifi 的方式上传输入方案。先删除 **Rime**、然后把 **IOS** 文件夹下的 **Rime** 上传即可。

上传之后，重新部署一下即可使用。
